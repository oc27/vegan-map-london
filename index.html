OPEN DATA · COMMUNITY MAINTAINED

A directory that gets better
when people contribute.

This first edition starts with 43 Instagram accounts supplied as a seed list. The list is deliberately wider than the map: some places still need their current trading status, exact address or vegan credentials checked.

Found a mistake, closure, new branch or missing place? Use the venue’s Instagram or website to check details, then contribute an update through the project repository. A future version can add a public submission and moderation flow.

Map data © OpenStreetMap contributors. Map tiles and geocoding are provided by OpenStreetMap services. Venue details are a snapshot and can change; check with a venue before travelling.
