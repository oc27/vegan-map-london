This is a community-maintained guide, not an independently verified directory. Businesses, addresses, opening hours and vegan options may change. Please check details directly with each venue before visiting. We welcome corrections and updates from the community.

OPEN DATA · COMMUNITY MAINTAINED

A directory that gets better
when people contribute.

This project starts with a community seed list of London food businesses and Instagram accounts. It is intended as a useful starting point for discovering places, not as an endorsement or a guarantee of current details.

Found a mistake, closure, new branch or missing place? Please send us the details using the feedback form above. Your message is sent to the project team by email — there is no need to access GitHub or edit the repository. We want this guide to grow through shared local knowledge.

Map data © OpenStreetMap contributors. Map tiles are provided by OpenStreetMap. Venue details and map positions are a snapshot and may be approximate or out of date. Please check with each venue before visiting.
